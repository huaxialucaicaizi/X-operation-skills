# 改了不走样

> 来源：本页原则归纳自 [op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh) 的 SKILL.md（2026-09-23 修订版），用本项目自己的话重述，并按增长长文场景调整。Humanizer-zh 采用 MIT 许可，Copyright (c) 2026 歸藏。

## 优先级

改写时遇到冲突，按这个顺序取舍：

1. **信息和确定程度不变**：不新增，不遗漏，不加强。
2. **编辑范围不越界**：去 AI 味只是润色，不默认扩写、补论据或改观点。
3. **作者声音不变**：保留作者原有的语气和语域，不替作者加经历、情绪、结论。
4. **最后才是表达问题**：禁用写法清单排在前三条之后。

## 逐项对照

每处改写都对照原句，检查下面这些有没有变：

| 项 | 例：不能这样改（虚构） |
|---|---|
| 数字与单位 | 「约 20%」改成「20%」 |
| 否定 | 「没有显著变化」改成「变化不大」 |
| 条件 | 删掉「在付费用户中」 |
| 时间 | 「计划下季度上线」改成「已上线」 |
| 归因 | 「嘉宾认为」改成直接陈述 |
| 因果 | 「同期留存上升」改成「因此留存上升」 |
| 确定程度 | 「可能」改成「会」 |
| 范围 | 「一家公司」改成「很多公司」 |
| 比较对象 | 删掉「相比上一版」 |

任一项走样，撤回这处改写。

## 不做的事

- 原文没有细节时，不为了「具体」编造细节。
- 原文主张可疑时，单独指出，不悄悄改成另一个说法。
- 不用字数减少、命中数清零或「AI 味消失」代替上面的对照。
- 通顺的段落不为展示工作量强改。
