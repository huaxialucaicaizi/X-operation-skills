# 增长论点链

先写骨架，确认每一环都有证据，再写成文章。

```
读者业务问题
  ↓
竞争起点：公司当时在什么处境（证据）
  ↓
增长动作：对哪类人群，在哪个入口，推动哪个关键行为（证据）
  ↓
机制：为什么起作用，克服了什么阻力（嘉宾说法 / 本文推断）
  ↓
结果：数字或定性结果，带口径（证据 / 未披露）
  ↓
识别与放大：怎么发现有效，怎么加码（证据）
  ↓
条件：什么前提下可借鉴，什么情况下不适用
  ↓
国内借鉴：本文推断，写明前提
```

## 每个打法的六要素

| 要素 | 问题 |
|---|---|
| 人群 | 针对谁？ |
| 入口 | 用户从哪里进来？ |
| 关键行为 | 希望用户做什么？ |
| 阻力 | 原来是什么挡住了用户？ |
| 结果 | 发生了什么变化？口径是什么？ |
| 条件 | 换个产品、市场、阶段还成立吗？ |

缺哪个要素，就在正文里如实说明，或在待核问题里列出，不补编。

## 骨架自检

- 删掉所有例子后，论点还能连成一条线吗？
- 每一环能指到至少一个证据编号吗？
- 有没有哪一环其实是我们的推断，却写成了事实？
