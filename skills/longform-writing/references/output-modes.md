# 两种输出模式

| 项 | X 长帖 | X Article |
|---|---|---|
| 适合的材料 | 一个增长动作、一条主证据 | 多个动作或一个动作的完整链条 |
| 标题 | 通常没有独立标题，首句承担标题作用 | 独立标题 |
| 结构 | 不用小标题；靠段落顺序推进 | 可用小标题分节 |
| 配图 | 可选，通常 0–1 张 | 头图 + 按需正文图 |
| 开头 | 第一句就是结论或问题 | 第一段给结论和读者收获 |
| 结尾 | 停在适用条件或一个可试的动作 | 适用条件 + 国内借鉴（标明推断） |
| 篇幅 | 服从材料；平台字数上限以当前规则为准（待补充） | 服从材料；平台限制以当前规则为准（待补充） |

## 怎么选

- 证据卡只够支撑一个动作：选 X 长帖。
- 需要对比两个以上案例或画图说明：选 X Article。
- 拿不准：在大纲提案里两种都写一句理由，由作者选。

## 共同要求

两种模式的事实规则完全一样：核验表、三层分开、数字口径、不编造。模式只影响结构和篇幅，不影响证据标准。
