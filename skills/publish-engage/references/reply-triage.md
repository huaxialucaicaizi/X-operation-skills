# 回复分诊

先分类，再决定要不要写草稿。

| 类别 | 判断 | 处理 |
|---|---|---|
| 有实质观点 | 原帖或评论提出了具体做法、数据或判断 | 写草稿：补一条我们有证据的增量观点 |
| 具体问题 | 有人问了能用我们材料回答的问题 | 写草稿：直接回答，附来源 |
| 泛泛互动 | 「好帖」「学到了」 | 不写草稿 |
| 噪音/引战 | 广告、攻击、无关 | 不写草稿，不回应 |
| 超出材料 | 问题我们没有证据回答 | 不写草稿，或草稿写「这点我们没有材料」 |

## 别人热门帖下的回复

- 先读原帖和上下文，确认我们的观点和原帖主题相关。
- 只补增量：原帖没说、我们有证据的那一点。
- 不借热门帖推销自己的文章；是否附链接由作者决定。
- 不写「好帖」「赞同」这类无信息回复。

## 草稿要求

- 事实规则和正文一样：有来源，不编数字。
- 语气按作者已确认偏好；没有偏好就保持平实。
- 每条草稿单独等授权。
