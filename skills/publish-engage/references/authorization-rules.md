# 授权规则

## 什么算授权

- 作者看过预览包中的**这一条**，并明确说「发」。
- 授权只覆盖：这个账号、这个平台、这个版本、这一条。

## 什么不算授权

- 「都可以」「看着办」「差不多」
- 对上一版本的「发」（版本已变）
- 对另一个平台的「发」
- 对正文的「发」不包含互动；对 X 的「发」不包含公众号

## 需要分别授权的动作

| 动作 | 是否需要单独授权 |
|---|---|
| 发布 X 长帖 / X Article | 是，逐条 |
| 发布回复 | 是，逐条 |
| 点赞、转发、私信 | 是，逐条；默认不做 |
| 存公众号草稿 | 是 |
| 公众号发布 | 不由本入口执行 |
| 外部归档（如文档库） | 是 |
| 跨平台同步 | 是，逐平台 |
| 定时发布 | 是 |

## 失败处理

- 登录失效、验证码、平台拒绝、页面报错：停下，报告现象，等作者处理。
- 不换工具、不换账号、不改请求方式绕过。
- 不自动重试超过一次（如需重试，先问作者）。
