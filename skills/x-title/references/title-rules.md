# 标题规则（简版）

完整版见 [X-title-skill](https://github.com/huaxialucaicaizi/X-title-skill)。这里只列本套件调用时必须遵守的部分。

## 五条基本面

1. **学结构，不学新闻腔**：想清「熟悉对象 + 具体动作 + 意外结果或问题」，不靠「刚刚」「突发」「炸了」「最强」。
2. **一个业务问题**：只回答一个具体问题，不把全文承诺成「全攻略」。
3. **真实反差**：反差来自事实和读者的合理预期，不伪造对立，不把多因素压成唯一原因。
4. **最多一个主数字，且有口径**：数字不是必选；时间、市场、分母、是否估算写不下，就不用这个数字。
5. **一个承诺，露一点答案**：告诉读者能带走什么，不用「到底做对了什么」这种空壳。

## 禁区（命中即淘汰）

- 改动事实，夸大范围或因果
- 假独家、假实测、假内部消息
- 时间压缩、制造恐惧（「一夜之间」「彻底完了」）
- 补造正文没有的身份、经历、数字、结果
- 超过 5 个正式候选；点击率预测；伪精确总分
- 修改作者已定稿的标题

## 检查项

| 检查 | 问题 |
|---|---|
| 正文兑现 | 标题每个承诺在正文哪一段兑现？ |
| 事实口径 | 动作、因果、比较范围、数字口径是否和证据表一致？ |
| 手机显示 | 对象和核心问题是否前置？未实机预览就标「待实机预览」 |
| 朗读 | 读出来是否自然，有没有黑话和翻译腔 |
| 取舍库 | 是否重复了作者否掉过的角度或写法 |

## 两种输出模式下的标题

- **X Article**：独立标题，按上面全部规则。
- **X 长帖**：没有独立标题字段时，「标题」就是首句。首句同样适用五条和禁区，并且要在手机信息流中不展开时也能看懂。
