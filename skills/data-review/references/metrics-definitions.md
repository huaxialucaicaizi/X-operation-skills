# 指标口径

## 原始指标

| 指标 | 说明 | 看不到时 |
|---|---|---|
| 公开 views | 帖子页面公开显示的数字 | NA |
| 后台 impressions | 后台分析中的曝光数 | NA（与 views 分列，不互相替代） |
| 赞 | | NA |
| 回复 | 区分原帖收到的回复与我们发出的回复 | NA |
| 转发 / 引用 | 分开记录 | NA |
| 收藏 | 只在可见时记录，不估算 | NA |
| 单帖带来的关注 | 只在平台单帖数据可见时记录 | NA；不从周净增粉分摊 |
| 链接点击 | 只在可见时记录 | NA |

每个数字都写采样时间和数据来源（页面 / 导出文件 / 截图）。

## 观察窗

- 常用：发布后 24 小时、7 天。具体窗口由作者定。
- 同一张对比表只用同一个观察窗。
- 采样时间与观察窗终点相差较大时，在备注里写明。

## 比例指标

以「每千次曝光」为单位：

```
每千曝光回复 = 回复 / 曝光 × 1000
```

- 分母写清用的是 views 还是 impressions。
- 分子或分母为 NA 时，结果为 NA。

## 解读边界

- 写出每组样本数 n。
- 只说「这一组在这个窗口里表现较高/较低」，不说「因为……所以……」。
- 至少写一个其他可能的解释（发布时间、话题热度、外部转发等）。
