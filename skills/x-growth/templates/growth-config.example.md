# 涨粉配置（示例）

> 复制到 `local/growth-config.md` 后填写（`local/` 已在 .gitignore 中忽略）。本文件只放占位符，不要把真实账号、粉丝数或个人信息提交到仓库。
> 未填写的项保持「待补充」；x-growth 入口会原样输出「待补充」，不猜。

## 账号

| 项 | 值 |
|---|---|
| 账号 | `@<your_handle>`（待补充） |
| 目标读者 | 待补充（例：做产品、增长和 AI 业务的人） |
| 已批定位句 | 待补充 |
| 账号可用能力（Article、长帖、后台数据等） | 以账号实际可见为准，待补充 |

## 目标

| 项 | 值 |
|---|---|
| 目标粉丝数 | 待补充（目标，不是效果承诺） |
| 起算日期 | 待补充 |
| 结束日期 | 待补充 |
| 启动时粉丝基线 | 待补充（启动当天从账号页面记录，写采样时间） |
| 基线采样时间 | 待补充 |

## 时间

| 项 | 值 |
|---|---|
| 时区 | 待补充 |
| 作者每日审核时间预算 | 待补充 |
| 次日预览准备时间 | 待补充 |
| 发后轻量检查时间 | 待补充（例：发后约 2 小时） |

## 内容节奏（默认值，可改）

| 项 | 默认值 | 性质 |
|---|---|---|
| 主语言 | 中文 | 默认 |
| 每日主槽位 | 1 | 默认 |
| 英文内容 | 每周 1–2 条，占用当日主槽位 | 默认，可改为「额外发布」 |
| 周配比 | 拆解 4 / 清单流程 2 / 方法总结 1 | 试行值 |
| 每日回复草稿上限 | 3 | 试行值 |
| 试行期 | 待补充（例：2 周） | |

## 名单（只放本地）

| 类型 | 名单位置 |
|---|---|
| 互动候选账号 | 待补充（本地文件路径） |
| 社群 | 待补充 |
| 合作候选 | 待补充 |

## 不允许在配置中开启的项

自动发布、自动回复、自动关注/取关/点赞/私信、付费 X API、读取 Cookie、定时任务。这些不是配置项。
