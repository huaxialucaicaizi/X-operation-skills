# 转写与校对清单

## 开始前

- [ ] 来源已登记，已查重
- [ ] 确认用的是官方稿、第三方稿还是自行转写
- [ ] 按来源 ID 或内容哈希缓存，同一音频不重复转写

## 转写后

- [ ] 原始稿已单独保存，不再改动
- [ ] 校正稿另存，并记录改动（改了哪里、为什么）
- [ ] 读到稿子末尾，确认没有截断

## 时间连续性

- [ ] 时间戳来自转写工具或字幕文件，不是按字数估算
- [ ] 检查相邻段落时间是否有异常跳跃
- [ ] 抽听至少几处：开头、中段、结尾各一处（抽听数量由作者定，默认值待补充）
- [ ] 所有准备引用的数字和引语所在段，逐一抽听

## 说话人

- [ ] 主持人和嘉宾已人工标注
- [ ] 多人对话中不确定归属的句子，进疑点列表

## 专名与数字

- [ ] 公司、产品、人名、功能名进术语表，统一写法
- [ ] 数字原样记录单位和口径
- [ ] 听不清的数字标「疑点」，不猜

## 提炼证据卡

- [ ] 每张卡能落到获客/激活/留存/变现/扩张之一
- [ ] 动作、机制、结果分开写
- [ ] 嘉宾观点和本文推断分开
- [ ] 结果没有数字时写「未披露」

## 交付前

- [ ] 证据卡数量、疑点数量写在交付摘要里
- [ ] 明确写出「完整翻译待大纲获批后进行」
