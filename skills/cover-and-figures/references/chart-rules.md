# 图型与口径规则

## 先回答三个问题

1. 这张图证明哪个观点？
2. 比较的是哪些对象，在哪个维度上？
3. 这些数字的口径一致吗？

三个问题答不上来，不做图。

## 按信息关系选图型

| 信息关系 | 图型 | 注意 |
|---|---|---|
| 几个对象比大小 | 条形图 | 同一量纲；按数值或逻辑排序 |
| 随时间变化 | 折线图 | 时间间隔一致；缺失点不连线 |
| 先后步骤 | 流程图 | 步骤来自材料，不补编 |
| 逐层流失 | 漏斗图 | 每层分母写清 |
| 整体构成 | 堆叠条 / 表格 | 少用饼图；各部分之和要等于整体 |
| 多维对比 | 比较矩阵（表格） | 缺项写「未披露」 |
| 一个关键数字 | 大字卡片 | 数字下方写口径和来源 |

## 口径

- 同一张图的数字：时间窗、市场、分母、单位一致。
- 不同量纲（金额与人数、比例与绝对值）不共用一个轴。
- 估计值与官方值分开标注。
- 缺数留空，不插值，不估。

## 头图

- 系列识别：底色、版式、期次位置固定。
- 标题逐字，只可换行。
- 检查手机缩略图下标题主体是否仍可读。

## 检查记录必填项

- PNG 实际像素尺寸
- 图中每个数字对应的证据编号
- 标题逐字比对结果
- 手机裁切目检结果
