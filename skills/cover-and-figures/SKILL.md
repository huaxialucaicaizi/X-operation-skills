# 头图与正文配图 / Cover and Figures

头图建立系列识别，正文图帮助证明一个明确观点。

## 输入

- 已审定正文（审批记录中有「正文与标题审定」）
- 锁定标题（逐字）
- 期次或系列编号
- 已授权素材（logo、截图等，写明授权来源）
- 已核验数据（证据编号）
- 长文入口给出的「配图观点清单」

## 输出

- 头图两版
- 正文图（按配图观点清单）
- 每张图的 HTML 源文件、PNG、源数据表、检查记录，按 [templates/figure-brief.md](templates/figure-brief.md)

## 步骤

1. **写观点**：这张图让读者看懂哪一个观点？一句话。
2. **选比较维度和对象**：按 [references/chart-rules.md](references/chart-rules.md)。
3. **统一口径**：同一张图里的数字时间、分母、单位一致。
4. **选图型**：由信息关系决定（比较、趋势、流程、漏斗、构成）。
5. **排版**：按默认样式或作者自定样式。
6. **本地渲染**：HTML/CSS 加无头浏览器（如 Playwright）截图成 PNG，保证可复现。
7. **核对**：图中每个数字对照源数据表；标题逐字比对；打开实际 PNG 检查尺寸；模拟手机缩略图看裁切。

## 默认样式（可改）

| 项 | 默认值 |
|---|---|
| 底色 | 米色 `#F6EFE4` |
| X 头图 | 1500×600 |
| 公众号头图（如需） | 1410×600 |
| 正文图 | 1600×900 |

尺寸为本套件默认值，平台推荐尺寸以平台当前说明为准（待补充），实际发布前做实机预览。

## 规矩

- 观点先于维度，维度先于图型。
- 不把融资、发布、用户量等不同性质的事件放进同一比较。
- 公司要标名；不同量纲不共用一个比例轴。
- 收入、ARR、年化收入分开；WAU、MAU 分开。
- 缺数留空，写「未披露」；估计值注明来源。
- 标题逐字使用，只可换行，不改字、不删字。
- 正文审定前不做图。
- 不用 AI 生图生成公司指标、截图或 logo。
