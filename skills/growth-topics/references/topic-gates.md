# 选题门槛与排序

## 硬门槛（任一不过即淘汰）

| 检查 | 通过标准 |
|---|---|
| 增长环节 | 明确属于获客/激活/留存/变现/扩张之一 |
| 具体动作 | 能写出「谁，对哪类用户，做了什么」 |
| 机制 | 能解释为什么起作用，或明确标为「机制待补充」 |
| 证据 | 至少一条证据卡支撑，带时间戳或出处 |
| 条件 | 能说出至少一个适用前提或不适用情形 |

## 排序维度（过门槛后才排）

逐项写一句判断，不打分，不加权求和。

- **可执行性**：读者看完能不能在自己的产品里试一个动作
- **信息增量**：和中文已有同题内容相比，多了什么（新材料、新机制解释、新条件）
- **新近程度**：材料是不是近期的；旧材料是否仍成立
- **AI 场景**：是否涉及 AI 产品的增长问题（加分项，不是门槛）
- **取舍库**：是否与作者已确认偏好一致，是否踩到已否方向

## 包装角度（只服务表达）

| 角度 | 适用 | 不适用 |
|---|---|---|
| 反常识 | 材料里确实有与常见做法相反的事实 | 需要虚构一个「大多数人都错了」的对立面 |
| 拆机制 | 嘉宾讲清了因果链条 | 只有结果没有过程 |
| 流程 | 有可复述的步骤 | 步骤是我们脑补的 |
| 对比 | 有两个以上可比对象，口径一致 | 对象性质不同（如融资事件对比用户规模） |
| 一手材料 | 嘉宾亲口说的内部做法 | 二手转述 |

## 常见淘汰理由（可直接写进取舍库）

- 落不到增长环节
- 只有观点没有动作
- 证据只有一句，且无口径
- 与已发内容重复，无新增量
- 需要制造对立面才成立
