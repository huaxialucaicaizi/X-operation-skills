# 版本与审批记录

> 每过一个闸门记一行。批准只对记录里的版本和范围有效，版本变了要重新批准。示例行为虚构。

| 日期 | 对象 | 版本 | 闸门 | 批准人 | 批准范围 | 备注 |
|---|---|---|---|---|---|---|
| 2026-01-01（虚构） | 大纲 | outline-v2 | 大纲确认 | 作者 | 可写全文、可整集翻译 | 虚构示例 |
| 2026-01-02（虚构） | 单条 X 长帖 | post-v3 + 图 v1 | 逐条发布授权 | 作者 | 仅此一条、仅 X、仅此版本 | 虚构示例 |
| | | | | | | |

闸门可选：大纲确认 / 正文与标题审定 / 配图确认 / 逐条发布授权 / 其他（写明）。

批准范围要写具体：哪个账号、哪个平台、哪个版本、是否含草稿箱或定时。没写到的范围视为未授权。
