# 证据卡

> 每条证据一张卡。下方为虚构示例，仅示范填法。

## E-001（虚构示例）

| 项 | 内容 |
|---|---|
| 来源 | S-001，时间戳 00:00:00–00:00:00（虚构） |
| 增长环节 | 获客 / 激活 / 留存 / 变现 / 扩张（选一） |
| 对象 | 哪类用户、哪个产品阶段 |
| 动作 | 公司具体做了什么 |
| 机制 | 为什么这个动作会起作用（嘉宾说法 / 本文推断，二选一并标明） |
| 结果 | 原话或原始数字；没有就写「未披露」 |
| 口径 | 时间、市场、分母、是否估算 |
| 适用条件 | 什么前提下可借鉴，什么情况下不适用 |
| 原文摘录 | 英文原句（逐字） |
| 中文转述 | 意思一致的中文，不加料 |
| 核验状态 | 未核 / 已核一次 / 双核 |
| 疑点 | 无 / 具体描述 |
